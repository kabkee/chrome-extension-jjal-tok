# 아이콘 파일

현재 아이콘 파일이 없습니다. 다음 방법으로 아이콘을 추가하세요:

## 방법 1: 온라인 도구 사용

1. [Favicon Generator](https://favicon.io/) 방문
2. 텍스트나 이미지로 아이콘 생성
3. 16x16, 48x48, 128x128 크기로 다운로드
4. 이 폴더에 `icon16.png`, `icon48.png`, `icon128.png`로 저장

## 방법 2: 직접 제작

Figma, Photoshop 등으로 다음 크기의 PNG 파일 제작:
- icon16.png (16x16)
- icon48.png (48x48)
- icon128.png (128x128)

## 임시 아이콘

개발 중에는 간단한 이모지를 사용할 수 있습니다:
💬 또는 🎬 이모지를 PNG로 변환하여 사용

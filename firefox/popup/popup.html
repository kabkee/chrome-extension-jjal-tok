저장된 GIF가 없습니다

웹페이지에서 GIF를 더블클릭하여 저장하세요

📌 짤톡 사용법

  1. GIF 저장하기:
    웹페이지에서 GIF를 더블클릭하거나 우클릭 → "짤톡에 저장"
  2. 저장된 GIF 확인:
    팝업에서 썸네일을 클릭하면 파일 위치가 열립니다
  3. 카카오톡으로 전송:
    파일을 카카오톡 채팅창으로 드래그하여 전송!
  4. 같은 GIF 다시 더블클릭:
    새로 받지 않고 목록 맨 위로 올린 뒤 파일 위치를 엽니다
  5. 삭제:
    목록과 함께 실제 파일도 삭제됩니다
  6. 동기화:
    Finder에서 지운 파일을 목록에서 빼고, 목록에 없는 파일을 찾아 정리합니다

💡 Tip: 최대 20개의 GIF가 자동으로 관리됩니다
